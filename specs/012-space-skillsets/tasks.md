# Tasks: Per-Project Skills for Claude Sessions

**Input**: Design documents from `/specs/012-space-skillsets/`

**Prerequisites**: plan.md, spec.md, research.md, data-model.md, contracts/project-skills-lib.md, contracts/ui.md, quickstart.md

**Tests**: No test tasks (not requested; the repo has no test suite). Each story ends with `herdr-app check` and the matching quickstart scenario (constitution III).

**Organization**: Tasks are grouped by user story so each story can be implemented and checked on its own.

## Format: `[ID] [P?] [Story] Description`

- **[P]**: Can run in parallel (different files, no dependencies)
- **[Story]**: US1–US4 from spec.md
- Paths are relative to `~/.config/herdr-app/`

## Rules that apply to every task

- Never write to `skills/`, `mcp/` or `~/.claude/` from code (FR-004, SC-005).
- File work runs inside `cx.spawn`; `render()` never calls `cx.notify()`; no `setTimeout`/`setInterval` (constitution IV).
- Edit `lib/project-skills.js` only; the copies in mods are GENERATED by `scripts/sync-github-lib.sh` and never edited by hand.
- Pass paths to `exec` as separate argv items (no shell strings).
