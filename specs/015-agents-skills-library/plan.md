# Implementation Plan: Skill Library Moves to `.agents/skills/`

**Branch**: `015-agents-skills-library` (no branch created, work on `master`) | **Date**: 2026-11-16 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/015-agents-skills-library/spec.md`

## Summary

Move the skill library from `skills/` to `.agents/skills/`, the folder the `skills` CLI's `universal` target writes, so `npx skills add <repo> -a universal` installs straight into Herdr's library. One change of `skillsDir()` in `lib/project-skills.js` (synced into `project-settings` and `my-new-menu`), two path strings in the Skills tab, notes in `CLAUDE.md`, and a one-time dependency-free Node script that moves the 41 folders, re-points every project's plugin-folder links, and re-syncs the lib. `skills-lock.json` and all `skills.json` selections stay as they are (research R2).

## Technical Context

**Language/Version**: plain JavaScript (gpui-kit mods, hot-reloaded); Node 24 for the one-time script

**Primary Dependencies**: none new. `skills` CLI via `npx` (user tool, not a repo dependency)

**Storage**: files: `.agents/skills/<name>/`, `skills-lock.json`, `projects/<slug>/skills.json`, `projects/<slug>/claude-plugin/skills/` symlinks

**Testing**: no test setup (constitution III); `herdr-app check` per mod + the runnable checks in [quickstart.md](quickstart.md)

**Target Platform**: macOS, Herdr desktop app

**Project Type**: desktop-app config home (mods + shared lib + scripts)

**Performance Goals**: n/a (one-time move of ~19 MB, 41 folders, same filesystem rename)

**Constraints**: no window where a project's skills are lost for good; renames kept in git; nothing written to `~/.claude/`, `mcp/`, selections

**Scale/Scope**: 41 library skills, 3 project folders under `projects/`, 2 mods using the lib

## Implementation order

1. `lib/project-skills.js`: `skillsDir()` + header comment (lib is not loaded directly; no effect yet).
2. `mods/project-settings/main.js`: path line and hint use `mcpDir()` (works for both old and new layout, safe to land first).
3. Write `scripts/migrate-agents-skills.mjs` per [contracts/migrate-script.md](contracts/migrate-script.md); run `--dry-run` and read the report.
4. Run the script: preflight → move → `rmdir skills` → repair links for all projects → `sync-github-lib.sh` (mods reload on the new path).
5. `herdr-app check mods/project-settings`, `herdr-app check mods/my-new-menu`, `herdr-app status`, `herdr-app shot` of the Skills tab.
6. `CLAUDE.md`: Per-project skills section.
7. Run [quickstart.md](quickstart.md) end to end, including a second script run.
8. `git add -A skills .agents/skills skills-lock.json lib mods/project-settings mods/my-new-menu scripts CLAUDE.md specs/015-*`; commit when the user asks.

## Risks

| Risk | Mitigation |
|---|---|
| Skills tab syncs with old code between move and lib sync, removes all links | Script step 3 creates missing links from `skills.json` (R4); steps 2–4 run inside one script |
| Running Claude sessions lose skills | Links re-pointed in place within the same run; same folder path, so sessions see them again |
| `skills remove -a universal` silently does nothing | CLAUDE.md documents `npx skills remove <name> -y` without `-a` (R2) |
| Agents that auto-load `.agents/skills/` (Codex, Cursor…) opened inside this repo see the whole library | Accepted in spec Assumptions |
