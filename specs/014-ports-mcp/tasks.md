# Tasks: Ports Tool for Claude (MCP)

**Input**: Design documents from `/specs/014-ports-mcp/`

**Prerequisites**: plan.md, spec.md, research.md, data-model.md, contracts/mcp-tools.md, quickstart.md

**Tests**: No test tasks (not requested; no test suite). Verification: `herdr-app check`, `node --check`, the stdio smoke test and scenarios in quickstart.md.

**Organization**: grouped by user story.

## Format: `[ID] [P?] [Story] Description`

- **[P]**: Can run in parallel (different files, no dependencies)
- **[Story]**: US1–US4 from spec.md
- Paths are relative to `~/.config/herdr-app/`

## Rules for every task

- `lib/ports.js` imports nothing from `herdr`; every function takes an injected `exec(cmd, args, opts) → Promise<{ code, stdout, stderr }>`.
- The copy `mods/project-settings/ports.js` is GENERATED by `scripts/sync-github-lib.sh`; never edit it.
- The server is read-only: it never sends signals, never writes files. Its stdout carries only JSON-RPC lines; logs go to stderr.
- Paths go to `exec` as separate argv items (no shell strings), except the `sh -c` launcher in `mcp/herdr-ports.json`.
